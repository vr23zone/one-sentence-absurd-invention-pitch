This program writes a single sentence pitching a ridiculous invention to
`/output/entry.txt`.

The sentence it writes:

> A toothbrush that goes on strike every morning you skip flossing, picketing the sink with a tiny sign that reads 'WE DEMAND FLOSS'.

Run it with `node main.ts` (Node 22). It uses only the Node standard library,
takes no input, and writes the sentence plus one trailing newline as UTF-8.
